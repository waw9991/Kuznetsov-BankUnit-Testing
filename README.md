## Открытие в Visual Studio

Нужны Windows и Visual Studio 2022 версии 17.8 или новее с компонентом «Разработка классических приложений .NET» и средствами .NET 8.
Проверено в Visual Studio Community 2026 18.4.2, .NET SDK 10.0.201; целевая платформа проектов — .NET 8.

1. Открыть `KuznetsovBank.sln`.
2. Дождаться восстановления пакетов NuGet; для первого восстановления нужен интернет.
3. Назначить `Bank` запускаемым проектом.
4. Выполнить сборку и запуск F5 или Ctrl+F5.
5. Выбрать **Тест → Запуск всех тестов**.

## Проверка из терминала

```powershell
dotnet restore KuznetsovBank.sln
dotnet build KuznetsovBank.sln -c Release
dotnet test KuznetsovBank.sln -c Release
dotnet run --project Bank -c Release
```

Проверено 24.10.2026: **3 из 3 тестов пройдены**, пропущенных нет; сборка без ошибок и предупреждений.
Результаты сохранены в `docs/evidence`, настоящие снимки запущенных приложений — в `docs/images`.

Класс `BankAccount` и этапы поиска учебной ошибки следуют руководству Microsoft.
В тестах используются собственные данные: баланс 1800,00; списание 425,50; ожидаемый остаток 1374,50.
В `docs/evidence/BankAccount.initial.txt` сохранена **намеренно ошибочная учебная версия**, не включённая в сборку.
В окончательном `Bank/BankAccount.cs` списание уменьшает баланс.
